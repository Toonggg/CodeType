How it works

        

        

          

            Choose an example or load any code file, then type the code exactly as shown. Spaces,
            tabs and line breaks count: a wrong space turns red, and the challenge completes only
            when every character matches.
          

          

            Tab fills in the indentation the code expects at the cursor. With
            Auto-indent on, pressing Enter also adds the next line's indentation;
            turn it off in Options for a harder run.
          

          

            Speed counts correct characters per minute. Accuracy counts every key you typed, so
            fixing a mistake with Backspace does not erase it. Press Esc to pause
            or resume, and Esc twice to restart.
          

          

            Use Local file or paste a file URL with GitHub file.
            CodeType detects the file extension and applies the closest available syntax colors.
